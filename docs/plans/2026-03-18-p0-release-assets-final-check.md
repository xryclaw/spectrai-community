## 3. 最终可发布版文案（按当前产品能力）

> 以下版本已与当前产品可见交互对齐，可直接用于上线说明。

### 3.1 发布说明（面向用户）

**标题**
`P0 体验更新：会话异常提示更清晰`

**摘要**
`本次更新优化了会话创建与执行过程中的状态提示，帮助你更快判断当前进度并继续操作。`

**更新内容**
1. 新建会话失败提示更直观（在创建弹窗内直接展示失败原因）。
2. 权限确认流程更明确（在对话区可直接选择允许/拒绝）。
3. 会话异常状态更可见（如启动超时、卡住、恢复失败）。
4. 会话结束后可一键恢复继续对话。

**提示**
`若你连续遇到同类失败，请保留会话并反馈发生时间与操作步骤，我们将优先处理。`

### 3.2 错误态恢复指引（面向用户）

**A. 创建失败（校验/资源/配置）**
- 你会看到：创建弹窗中的红色错误提示
- 你可以做：检查工作目录、Provider 配置后再次点击“创建”

**B. 权限确认**
- 你会看到：对话区“允许/拒绝”确认栏
- 你可以做：
1. 选择“允许”继续当前操作
2. 选择“拒绝”并改为输入下一步指令

**C. 启动超时或卡住**
- 你会看到：会话顶部/会话项出现“启动超时/卡住”类提示
- 你可以做：
1. 先等待短时间观察状态恢复
2. 如会话已结束，点击“恢复会话继续对话”
3. 必要时重新创建会话

**D. 恢复失败或其他异常**
- 你会看到：右下角“恢复失败”提示或会话状态为“出错”
- 你可以做：
1. 再次尝试恢复
2. 保留会话并记录操作步骤，提交给支持团队

### 3.3 FAQ（面向支持/运营）

**Q1：看到“创建会话失败”该如何引导？**
A：先让用户检查工作目录和 Provider 配置，再重试创建。

**Q2：权限弹窗里选“拒绝”后会中断吗？**
A：不会强制中断，用户可继续输入后续指令。

**Q3：出现“启动超时/卡住”怎么办？**
A：先短暂等待；若会话已结束，建议点击“恢复会话继续对话”；仍失败则重建会话。

**Q4：恢复失败后下一步怎么做？**
A：建议再次恢复一次；若仍失败，请记录时间点和操作步骤后反馈。

**Q5：为什么发布说明不写“一键切换 Provider”？**
A：当前版本尚未在错误面板中提供该直接按钮，为避免用户误解暂不对外承诺。
