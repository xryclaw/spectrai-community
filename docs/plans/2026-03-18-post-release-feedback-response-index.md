## 1) 问题分类总览（五类）

1. 功能类：按钮/入口/流程与预期不一致，或提示文案与实际行为不符。
2. 性能类：响应慢、卡顿、重复重试后才成功、偶发恢复延迟。
3. 权限类：用户不理解允许/拒绝，或权限确认后流程异常。
4. 超时类：启动超时、会话卡住、恢复失败后反复出现。
5. 未知类：无法归入以上类型，或提示不明确、偶发且难复现。

## 4) 升级到前端/后端/QA 的判定条件（简版）

### 升级前端

1. 用户找不到入口或按钮文案与页面行为不一致。
2. 错误提示缺少下一步动作，用户无法自助恢复。
3. 同一问题在不同页面描述不一致。

### 升级后端

1. 创建/恢复/权限响应出现状态错乱或无响应。
2. 同参数请求结果不稳定（有时成功有时失败）。
3. 多用户同时间段出现同类失败。

### 升级 QA

1. 支持无法稳定复现，需要复现路径固化。
2. 修复后需验证是否回归影响主流程。
3. 用户反馈“修复后仍偶发”，需回归矩阵验证。

## 5) 支持使用步骤（建议流程）

1. 先按“分类总览”给问题归类（最多 30 秒）。
2. 在对应行复制“首轮回复话术”发给用户。
3. 按“升级判定”决定是否立即升级工程侧。
4. 在工单记录 FAQ 编号与最终分类，便于后续复盘。
