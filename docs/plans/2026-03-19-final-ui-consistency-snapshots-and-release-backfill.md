## 2) 发布说明回填条目（可直接粘贴）

### 2.1 界面变更点（用户可见）

1. 设置页升级为全屏结构：
- 由原弹窗形态升级为全屏设置工作台，采用“左侧导航 + 右侧内容区”布局，提升多模块配置效率。

2. 设置离开保护：
- 当通用设置存在未保存修改时，按 `Esc` 或点击关闭将弹出确认，避免误关闭导致配置丢失。

3. 通用设置交互优化：
- 代理设置新增保存中状态与防重复提交，提交反馈更明确。
- 通用Tab在切换其他Tab后返回时保留未提交草稿输入。

4. Sidebar 与设置页联动：
- Sidebar 的“前往设置→工作区”支持一跳进入设置页工作区Tab，降低路径成本。

5. Markdown 渲染统一：
- assistant 消息统一采用 Markdown 渲染链路（GFM + 代码高亮），链接行为、表格滚动与文本样式在会话中保持一致。
- 流式输出阶段与完成阶段渲染策略明确（流式纯文本、完成后Markdown）。

### 2.2 用户影响说明

1. 正向影响：
- 配置路径更清晰，设置与会话阅读的一致性更高。
- 减少误操作与重复提交造成的配置失败概率。

2. 使用变化：
- 设置页不再是中心弹窗，而是全屏页面；关闭行为在有未保存改动时会增加确认步骤。

### 2.3 回归关注点（发布同步给 QA）

1. 设置页关闭与未保存确认是否在所有入口一致触发。
2. Sidebar 跳转到工作区设置是否稳定命中目标 Tab。
3. Markdown 在长表格、代码块、流式转完成态下样式是否一致。
