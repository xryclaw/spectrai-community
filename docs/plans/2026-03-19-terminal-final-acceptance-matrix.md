## 执行约定

- 执行环境：最新联调分支 + 可启动桌面端应用（Electron）
- 执行方式：按用例顺序执行；每条用例记录 `Pass/Fail` 和实际现象
- 统一标记：`P0` 为阻断发布项，任一失败即 `NO-GO`

## 全局前置条件

1. 应用可正常启动并进入主界面
2. 当前用户有本地终端可执行环境（`zsh`、`bash`、`sh`）
3. 至少存在一个可读写工作目录
4. 日志面板可查看会话状态变化（用于异常场景核对）

## 用例矩阵

### TFA-001（P0）入口按钮位置与可见性

- 前置条件：应用启动完成，主界面布局未被遮挡
- 步骤：
  1. 观察主界面左下角区域
  2. 缩放窗口到最小可用尺寸（宽度约 1024，高度约 700）
  3. 再次观察左下角入口按钮是否仍可见、可点击
- 预期结果：
  1. 左下角存在终端入口按钮（图标/文案与设计一致）
  2. 在正常窗口与最小尺寸下均不被遮挡
  3. hover/active 状态可见，点击有响应
- 结果记录：Pass / Fail

### TFA-002（P0）底部终端面板展开

- 前置条件：入口按钮可见
- 步骤：
  1. 点击左下角终端入口按钮
  2. 观察底部会话区域
- 预期结果：
  1. 底部出现终端面板
  2. 面板默认激活一个终端实例（含可输入区域）
  3. 主内容区与底部面板布局无重叠错位
- 结果记录：Pass / Fail

### TFA-003（P0）底部终端面板收起与恢复

- 前置条件：底部终端面板已展开且存在至少 1 个终端实例
- 步骤：
  1. 点击收起按钮（或同一入口切换）
  2. 确认底部面板收起
  3. 再次展开底部面板
- 预期结果：
  1. 面板可成功收起且不残留遮挡层
  2. 再次展开后恢复到上次激活终端标签
  3. 收起前运行中的终端任务不中断
- 结果记录：Pass / Fail

### TFA-004（P0）右上角新增终端（zsh）

- 前置条件：底部终端面板已展开
- 步骤：
  1. 在终端窗口右上角点击“新增终端”
  2. 选择 `zsh`
  3. 在新终端输入 `echo ZSH_OK` 并回车
- 预期结果：
  1. 新增一个 zsh 终端标签
  2. 标签标题或元信息能识别为 zsh
  3. 输出包含 `ZSH_OK`
- 结果记录：Pass / Fail

### TFA-005（P0）右上角新增终端（bash）

- 前置条件：已存在至少 1 个终端
- 步骤：
  1. 点击“新增终端”
  2. 选择 `bash`
  3. 输入 `echo BASH_OK` 并回车
- 预期结果：
  1. 新增 bash 终端标签
  2. 输出包含 `BASH_OK`
  3. 其他终端标签不被重置
- 结果记录：Pass / Fail

### TFA-006（P0）右上角新增终端（sh）

- 前置条件：已存在至少 2 个终端
- 步骤：
  1. 点击“新增终端”
  2. 选择 `sh`
  3. 输入 `echo SH_OK` 并回车
- 预期结果：
  1. 新增 sh 终端标签
  2. 输出包含 `SH_OK`
  3. 标签数量 +1，已有标签状态保持不变
- 结果记录：Pass / Fail

### TFA-007（P0）左上角多标签切换

- 前置条件：至少存在 3 个不同 shell 终端标签
- 步骤：
  1. 依次点击左上角标签：zsh -> bash -> sh
  2. 每次切换后输入 `echo ACTIVE_<shell>`
- 预期结果：
  1. 切换立即生效，当前标签高亮正确
  2. 每个标签保留各自历史输出和光标上下文
  3. 不出现跨标签输出串流
- 结果记录：Pass / Fail

### TFA-008（P0）异常终端关闭（进程异常退出）

- 前置条件：至少有 2 个终端实例运行
- 步骤：
  1. 在其中一个终端执行 `exit 1`（或等价异常退出命令）
  2. 观察该标签状态与 UI 提示
  3. 继续在另一个终端输入 `echo STILL_ALIVE`
- 预期结果：
  1. 异常终端被标记为已退出/异常
  2. UI 提示明确，不导致整个底部面板崩溃
  3. 其他终端可继续正常输入输出（含 `STILL_ALIVE`）
- 结果记录：Pass / Fail

### TFA-009（P1）手动关闭单个终端

- 前置条件：至少有 3 个终端标签
- 步骤：
  1. 关闭中间一个终端标签
  2. 观察剩余标签排序与激活项
- 预期结果：
  1. 仅目标标签关闭，其他标签保留
  2. 自动切换到相邻标签，不出现空白面板
  3. 标签索引与内容映射一致
- 结果记录：Pass / Fail

### TFA-010（P0）多个终端并发输入

- 前置条件：至少有 3 个终端标签（zsh/bash/sh）
- 步骤：
  1. 在 zsh 输入：`for i in 1 2 3; do echo Z:$i; sleep 1; done`
  2. 立即切到 bash 输入：`for i in 1 2 3; do echo B:$i; sleep 1; done`
  3. 立即切到 sh 输入：`for i in 1 2 3; do echo S:$i; sleep 1; done`
  4. 循环切换标签观察输出
- 预期结果：
  1. 三个终端各自持续输出，不互相污染
  2. 切换过程中无卡死、无整面板重置
  3. 输出顺序与各自命令一致
- 结果记录：Pass / Fail

### TFA-011（P1）面板收起后的并发任务保活

- 前置条件：至少 2 个终端正在执行耗时命令（>10s）
- 步骤：
  1. 收起底部终端面板
  2. 等待 10 秒
  3. 重新展开并查看输出
- 预期结果：
  1. 收起期间任务持续运行
  2. 展开后可看到连续输出，无明显断流
  3. 会话状态与任务实际运行状态一致
- 结果记录：Pass / Fail

### TFA-012（P1）异常 shell 不可用回退

- 前置条件：可临时制造某个 shell 不可用（例如移除 PATH 或 mock）
- 步骤：
  1. 点击新增终端并选择不可用 shell
  2. 观察错误提示与回退行为
- 预期结果：
  1. 明确提示 shell 启动失败原因
  2. 不影响已存在终端会话
  3. 支持用户重试或切换其他 shell
- 结果记录：Pass / Fail
